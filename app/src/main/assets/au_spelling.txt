# Pocket Dictate: US > Australian spelling list
#
# One rule per line:   US word > Australian word
# A line starting with ! keeps that exact word (capitals matter) unchanged.
# Anything after # is a note and is ignored.
# Words match whole words only, and capitals are kept: Color > Colour, COLOR > COLOUR.
#
# Deliberately NOT included, because Australian usage is the same as US or
# depends on meaning:
#   program (AU uses "program"), disk, draft, check/cheque, tire/tyre,
#   curb/kerb, story/storey, practice (noun) / practise (verb), meter/metre,
#   dialog (as in "dialog box"), inquire/enquire, mom/mum.
# "practicing" and "practiced" are always verbs, so they ARE converted.
# "license" is converted to the noun "licence"; fix by hand if you meant the verb.
